Methods, definitions & publishing guide

Data source and study population

Source: CDC WONDER underlying cause of death, including historical mortality series. Rates are restricted to non-Hispanic White (NHW) populations to improve comparability between states with different demographic profiles. This restriction does not eliminate differences in age, socioeconomic conditions, or other factors and does not describe all Iowa residents.

The supplied series spans 1968–2024. Historical race/ethnicity availability and definitions, ICD revisions, and age-standardization comparability must be checked against the original extracts; the file contains no extraction metadata to independently verify these details. Source rates are retained without reconstruction from counts.

Comparisons and uncertainty

Rates are used exactly as supplied. Verify units, age restrictions, age standardization, source, and release status before publication. They are not inferred from counts or population. The comparator is an unweighted state mean, not a pooled US rate.

Trend comparisons use a fixed cohort of other states with complete values in every observed year for the selected sex and measure. The 95% percentile interval resamples complete state trajectories 10,000 times using a seeded generator. It describes between-state variability under an exchangeable-state interpretation, not uncertainty in a literal finite-state mean, and does not propagate within-state rate uncertainty. Iowa trend CIs are intentionally omitted.

Ranks and the ratio

Ranks use the selected year, with 1 = highest and minimum ranks for exact ties. Missing observations are excluded and never replaced with older years. Rank uncertainty is not modeled. No source rate confidence intervals were supplied; rankings and maps display point estimates. The ratio is circulatory death counts / cancer death counts; it is not a ratio of age-adjusted rates. Zero or missing cancer counts yield missing ratios. Ratio intervals are not estimated.

Comparison Trends

Four sex-specific series share one y-axis: Iowa cancer, Iowa circulatory mortality, and the corresponding other-state means. Both comparison means use the same fixed cohort of states with complete cancer and circulatory rates in every observed year. Color identifies cause; solid circles identify Iowa and dashed squares identify other states. Shading shows the 95% state-bootstrap interval for each comparison mean. The measure selector applies to the summary cards and other views; Comparison Trends always shows both rates.

Map outlines: US state GeoJSON, PublicaMundi MappingAPI. Contiguous states use an Albers projection; Alaska and Hawaii are repositioned insets. Color scales are selection-specific.

Deploy to GitHub Pages

Upload this file as index.html at your repository root. Add your original tab-delimited file as data.tsv in the same folder, then enable Pages for that branch in repository Settings. No build, API key, external script, or analytics service is required. Files committed to a public repository are public. Visitors can instead load data locally; locally selected files are not uploaded.

Schema: State, State Code, Sex, Year, Population, Cancer-Deaths, Cancer-Rate, Heart-Deaths, Heart-Rate. Heart-Deaths and Heart-Rate represent all circulatory diseases in this dataset. Only the 50 US states and Female/Male records are analyzed; excluded records are reported.

Definition: “Heart” throughout this page refers to all diseases of the circulatory system in the supplied data, not heart disease alone. Cancer and circulatory diseases are compared as underlying causes of death; no formal competing-risks model is estimated.
